# Simulador
Empresa de logistica simulador

## UADE Wrapped

El script `uade_wrapped.py` utiliza Streamlit para mostrar un resumen de materias aprobadas, faltas y alertas de examen final. Para ejecutarlo, instale las dependencias:

```bash
pip install streamlit matplotlib pillow
```

Luego ejecute:

```bash
streamlit run uade_wrapped.py
```
